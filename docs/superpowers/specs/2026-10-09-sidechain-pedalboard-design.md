# Design: Real audio-level sidechain + pedalboard mastering backend (step 5 of roadmap)

**Date:** 2026-10-09 (rev. 3 — rev-1 blockers f1–f10 closed and re-verified; re-review findings r-f1…r-f12 closed) · **Status:** approved for implementation · **Branch:** `feature/sidechain-pedalboard`

Citation labels: **§2 rN** = Context-table row N; **fN** = rev-1 finding; **fN′** = rev-2 response; **r-fN** = rev-2 re-review finding.

## 1. Goal

Two audio-quality changes, from the roadmap's "Improve the Audio Processor" (high priority) and "Real sidechain (audio-level)" (advanced) items:

1. **Real audio-level sidechain** — the *rendered kick's amplitude envelope* (not note-start times) drives the duck applied to bass/leads/pads and the reverb bus.
2. **A `pedalboard` mastering backend** — JUCE-based EQ / compressor / brick-wall limiter where `pedalboard` is installed, with the pure-NumPy chain kept as the default fallback and as an explicit `"numpy"` backend.

The built-in synth + mastering path must keep working with **no external tools**, and same-seed output must stay **deterministic**.

## 3. Decisions

| # | Decision | Alternatives rejected |
|---|---|---|
| D1 | **Real audio-level sidechain (r-f3/r-f7/r-f8).** `synthesis/mixer.py` adds `from scipy import ndimage`. New `Mixer.audio_sidechain(kick, n, *, gate=SIDECHAIN["gate"], hold_ms=SIDECHAIN["hold_ms"]) -> np.ndarray`: accepts a `(n,)` **or** `(n, C)` kick buffer (a 2-D input is mono-ised with `mean(axis=1)`), zero-pads/truncates to length `n`; `env = ndimage.maximum_filter1d(np.abs(x), size=max(3, int(hold_ms/1000*sr)), mode="nearest")`; normalise by `env.max()`; return `np.clip((env - gate)/(1 - gate), 0, 1).astype(np.float32)`; all-silence ⇒ `zeros(n)`. The centered max-filter gives ~`hold_ms/2` lookahead so the duck is at full depth on the onset (r9; the limiter-style the lookahead is compensated by the symmetric filter). Config `SIDECHAIN = {"mode": "audio", "gate": 0.35, "hold_ms": 5.0, "release_ms": 110.0}`. `Mixer.__init__(..., sidechain_mode: Optional[str] = None)` resolves `self.sidechain_mode = sidechain_mode or SIDECHAIN["mode"]` **inside `__init__`** (not a default arg). `render_song_audio` renders the **kick track once**, reuses its stereo buffer in the loop, and uses `duck = mixer.audio_sidechain(kick_stereo, n)` in `"audio"` mode; otherwise (or no kick track but kick notes) `duck = mixer.sidechain_curve(kick_times, n, release=SIDECHAIN["release_ms"]/1000.0)` (r-f7 — `release_ms` now wired to the fallback); no kick at all ⇒ `duck = None`. `sidechain_curve` is **kept** (legacy mode, fallback). Reverb-bus duck keeps its `0.5` scale. | Envelope-follower `max(fast,slow)` (over-ducks — r9/f1). Onset detection + decay (double-fires 32/16 kicks via the body ripple). Per-onset **level** weighting of the note curve (no-op under uniform velocity). Adaptive **release** from kick decay (t30 uniform — r10). Full drum-mix trigger. A `Sidechain` class. GUI/web control. |
| D2 | **`PedalboardProcessor` + `get_processor()` (r-f1/r-f2/r-f4/r-f5/r-f6/r-f9).** Guarded import → `PEDALBOARD_AVAILABLE`. Behaviour-preserving refactor of `AudioProcessor`: extract the input handling (current lines 174-182) into `AudioProcessor._prepare(audio) -> np.ndarray`; **keep the `if x.shape[0] == 0: return x` short-circuit in `process`** (after `_prepare`) so empty input still returns empty (r-f4). Fix the mono crash (r-f5): `_compress` uses `det = np.maximum(np.abs(x[:, 0]), np.abs(x[:, -1]))` — bit-identical for stereo, works for mono. New `class PedalboardProcessor(AudioProcessor)` reuses the inherited `__init__` (validation), `_prepare`, `_widen`, `_normalize`; pedalboard stage methods are named **distinctly** so they never shadow the NumPy stages (r-f2): `_pb_eq` = `Pedalboard([HighpassFilter(highpass_hz) **for _ in range(4)**] + [PeakFilter(lowmid_hz, lowmid_db, 1.0), PeakFilter(presence_hz, presence_db, 0.8), HighShelfFilter(air_hz, air_db, 0.7)])` (r-f1 — **list comprehension**, never `[x]*4`); `_pb_compress` = `Pedalboard([Compressor(threshold_db, ratio, attack_ms, release_ms)])`; `_pb_limit` = `Pedalboard([BrickwallLimiter(ceiling_db=target_peak_db)])`. Each runs through `_run(board, x, sr)` which transposes `(n,C)→(C,n)`, calls `board(..., sr, reset=True)`, and transposes back to float32. `PedalboardProcessor.process(audio, sr)`: `x = self._prepare(audio)`; empty ⇒ return; **`x.shape[0] < 8` ⇒ `return self._normalize(x)`** (degenerate buffers skip filtering/compression — this is a defined NumPy-only path, not `super().process`, avoiding the dispatch trap); else `_pb_eq` → inherited `_widen` → `_pb_compress` → `_pb_limit` → inherited `_normalize`. **Three boards** (EQ / compress / limit), stated consistently (r-f6). `get_processor(backend=None)`: `backend or MASTERING.get("backend", "auto")` (key read at call time — patching by key is enough, r-f9); `"numpy"`→`AudioProcessor()`; `"pedalboard"`→`PedalboardProcessor()` or `raise RuntimeError(...)`; `"auto"`→pedalboard when importable else NumPy; else `ValueError`. `process_audio(input_file, output_file=None, processor=None, backend=None)`: `proc = processor or get_processor(backend)` — an explicit `processor` **wins** over `backend` (documented precedence, r-f9). `MASTERING["backend"] = "auto"`. `requirements.txt` gains `pedalboard>=0.9` (audio group, spec reference). | `[HighpassFilter(hz)]*4` (reuses one instance → RuntimeError — r-f1). Shadowing `_eq`/`_compress` (makes `super().process` re-enter pedalboard — r-f2). Replace `AudioProcessor`. New `mastering.py`. `Limiter` (makeup + 0 dBFS clip). 2× HPF (rumble 0.52 — r8). Interleaving `_widen` in one board (`StereoWidth` absent — r6). Mandatory pedalboard. |

## 4. Scope

**In:** D1 sidechain method + render-path reorder + `SIDECHAIN` config + `ndimage` import; D2 `PedalboardProcessor` + `get_processor` + `_prepare`/mono/empty refactor + `MASTERING["backend"]` + `requirements.txt`; D3 tests; D4 verification; D5 README; PR.

**Out (explicit):** musical variation / fills (step 6); stems / per-style SoundFonts / packaging (step 6); any change to sidechain *depths* (`MixSettings.sidechain`); FluidSynth-path sidechain (D6); a GUI/web control for sidechain mode or mastering backend; the review-loop global-param contract. (`AudioProcessor`'s DSP is unchanged except the mono-safety one-liner in `_compress` — bit-identical for stereo, r-f5.)

## 5. Risks

| Risk | Mitigation |
|---|---|
| Audio duck fails to recover (f1) | Peak-hold gate: measured **min 0.00** on all presets (r9); D3(a) pins recovery; `"note"` mode is a one-line revert |
| Audio duck lags the transient (f4) | Centered max-filter lookahead ⇒ **peak@0 ms, 3 ms = 1.00** (r9); D3(a) asserts onset alignment |
| pedalboard rumble contract (f2) | 4× `HighpassFilter` (distinct instances) ⇒ rumble 0.167 (< 0.5), bass 2.107 (> 0.7) (r8); `sosfiltfilt` squares the NumPy magnitude to 24 dB/oct = 4×1st-order |
| `[HighpassFilter(hz)]*4` reuses an instance (r-f1) | List comprehension, asserted by a chain-construction test |
| Method shadowing defeats the NumPy fallback (r-f2) | Distinct `_pb_*` names; the `<8`-sample path returns `_normalize(x)` directly (D2); `(2,2)`/`(1,1)` tests |
| `scipy.ndimage` not bound (r-f3) | `from scipy import ndimage` in `mixer.py` |
| Empty input regresses (r-f4) | Short-circuit stays in `process` after `_prepare`; empty-input test |
| NumPy backend crashes on mono (r-f5) | `_compress` uses `x[:, -1]`; mono test for both backends |
| `SIDECHAIN["release_ms"]` dead (r-f7) | Wired to the `sidechain_curve` fallback |
| `audio_sidechain` ambiguous (r-f8) | Documented shapes/length contract (D1) |
| `processor`+`backend` conflict (r-f9) | Precedence documented; read `MASTERING` by key at call time |
| Test song has no kick (r-f11) | Explicit assertion in D3(b) |
| Adding a dependency breaks the no-setup promise | **Optional**: `"auto"` falls back to NumPy; README says so; `AudioProcessor` tests unchanged |
| Kick rendered twice (perf) | Rendered once, buffer reused; ~1.6 s for a 3-min chain (r11) |
| pedalboard version drift | Tests run against the installed version; no byte-level cross-env assertions; `"numpy"` always available |
| Mastering failure loses audio | Unchanged: `generator.py` keeps the raw render (r5) |

## 6. Out-of-scope / follow-ups

- A fully audio-derived *trigger* (onset detection) was prototyped and rejected: it double-fires on low-frequency kick bodies (32 detections for 16 kicks on goa/hybrid). The peak-hold envelope (D1) is the robust equivalent.
- Per-onset release adaptation is deferred: rendered kick decay is uniform across presets (r10).
